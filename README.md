## Featured Projects

### 📄 DocuMind — RAG-based AI Document Expert

A Retrieval-Augmented Generation application designed to allow users to interact with complex documents through natural-language queries.

**Highlights:**

- RAG-based document question answering
- LangChain-based document processing
- Gemini-powered responses
- ChromaDB vector storage and similarity search
- Multi-document retrieval
- Firebase Authentication and Firestore
- Persistent cross-session chat history
- Streamlit-based interactive dashboard

**[View Repository](https://github.com/prernadangara/documind-rag)**

---

### 🤖 Vertexa — Customised LLM Chatbot

A domain-specific conversational AI chatbot built using **Google Cloud Vertex AI Agent Builder, Dialogflow CX, Datastore and Gemini**.

**Highlights:**

- Custom document-based knowledge source
- Datastore-based information retrieval
- Gemini 2.5 Flash
- Dialogflow CX intents and conversation flows
- Generative fallback for unmatched queries
- Multi-turn conversational interaction
- Conversational Messenger web interface

**[View Repository](https://github.com/prernadangara/vertexa-ai-chatbot)**

---

### 🏫 CampusResolve — Student Complaint Management System

A Firebase-powered web application for submitting, tracking and managing campus complaints through dedicated student and administrator portals.

**Highlights:**

- Firebase Authentication
- Cloud Firestore database
- Anonymous complaint submission
- Personal complaint tracking
- Admin complaint dashboard
- Category filtering and priority management
- Complaint resolution with administrator remarks
- Real-time campus announcements
- Firestore Security Rules for access control

**[View Repository](https://github.com/prernadangara/campus-resolve)**
